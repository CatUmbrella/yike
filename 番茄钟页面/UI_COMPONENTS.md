# 番茄钟页面 UI Components

> 基于 `yike/番茄钟页面.md`，同步更新于 2026-06-03。

## 1. 设计基调

延续当前 App 的 iOS / Apple HIG 风格：

- 浅色背景
- 蓝色作为主操作色
- 大圆角
- 克制阴影
- 清晰层级
- 不使用 Liquid Glass

番茄钟模块可以保留自定义番茄图标，但整体仍保持当前安排页的蓝色体系。

自定义番茄图标素材已存在。接入时优先使用透明背景 PNG/WebP，建议正方形资源；如果素材带背景，先按静态图标接入，后续再根据视觉效果处理裁切或去背景。

## 2. PomodoroHomePage 组件

### PomodoroHistoryPreview

位置：主页顶部。

视觉权重：低，偏小。

内容：

- 标题：历史记录
- 右上角：“查看全部>”，灰色
- 最近 2-3 条历史记录

单条记录：

```text
[事件 summary/title]      [🍅 🍅 🍅 / 番茄×4]
[完成/更新时间]            [已完成 / 未完成]
```

规则：

- 标题使用 `summary` 字段，summary 为空时回退到 title。
- 番茄最多显示 3 个自定义番茄图标。
- 超过 3 个番茄显示为 `番茄×N`。
- `completed_at` 不为空时显示已完成，时间用 `completed_at`。
- `completed_at` 为空时显示未完成，时间使用 session 的 `updated_at`。

交互：

- 点击“查看全部>”进入历史记录详细页。

状态：

- loading
- empty
- loaded

### PomodoroEventBox

位置：主页中间。

视觉权重：中上。

说明：

- 参考安排页事件箱视觉设计。
- 不复用安排页“点击空白进入录入页面”的逻辑。
- 不复用四象限上色逻辑。
- 事件胶囊默认浅蓝色，和安排页事件箱中默认胶囊颜色一致。
- 左侧复选框可交互。

单条事件卡：

```text
[checkbox] [summary/title]              [预计耗时]
```

选中态：

- checkbox 打勾。
- 事件胶囊背景变为深蓝色。
- 文本颜色切换为适合深蓝底的高对比颜色。

交互：

- 点击事件卡或 checkbox：选中该事件。
- 再次点击：取消选中。
- 同一时间只允许选择一个事件。

### PomodoroStartPanel

位置：主页底部。

形态：圆角矩形框。

未选中事件时：

```text
选择一个任务
点击选择事件箱中的任务开始专注                         [番茄图标]
```

视觉：

- 整体灰色 disabled。
- 不可点击。

选中事件后：

```text
[选中事件 summary/title]
预计专注时间：X h X m                                  [番茄图标]
```

视觉：

- 整体蓝色 enabled。
- 点击后 push 番茄钟计时页面。
- 右侧固定显示自定义番茄图标。

### PomodoroHomeAddButton

位置：主页浮动按钮。

说明：

- 从主页复用添加按钮。
- 交互逻辑和安排页添加按钮一致。
- 点击进入事件录入页。
- 支持可拖动和吸附逻辑。

## 3. PomodoroTimerPage 组件

计时页面共有四个主要组件：

1. 计时器
2. 打断
3. 想法
4. 步骤

底部另有固定操作区：暂停/继续按钮 + 结束专注。

### PomodoroTimerDisplay

位置：计时页顶部。

内容：

- 大号计时器：`00:00:00`
- 小字状态：
  - running：专注中
  - paused：暂停中

视觉：

- 不需要矩形框，直接放在背景上。
- 正在计时使用主蓝色或高亮色。
- 暂停中使用灰色或低饱和提示色。

### PomodoroLanePanel

通用结构，用于“打断”“想法”“步骤”三个板块。

结构：

```text
┌─────────────────────────────────────────┐
│ 左侧竖排标签 │ 分割线 │ 右侧可滑动内容区域 │
└─────────────────────────────────────────┘
```

左侧区域：

- 固定窄宽。
- 文字垂直排列。
- 用于触发新增或标识板块。

右侧区域：

- 圆角矩形内容区。
- 内容超出时横向或纵向滚动，按具体板块决定。

### InterruptionPanel

左侧竖排标签：

```text
+打断
```

交互：

- 点击左侧“+打断”弹出 `InterruptionInputDialog`。
- 弹窗用于录入打断缘由，MVP 可先做占位。

右侧内容：

```text
[打断缘由]                         [记录时间]
```

状态：

- 未解决：正常颜色。
- 已解决：文字划横线，整体变灰。

后台记录：

- 记录具体时间。
- 记录番茄钟进行到多少分钟/秒时产生该打断。

### IdeaPanel

左侧竖排标签：

```text
+想法
```

交互：

- 点击左侧“+想法”弹出 `IdeaInputDialog`。
- 弹窗用于录入具体想法，MVP 可先做占位。

右侧内容：

```text
[想法内容]                         [记录时间]
```

后台记录：

- 记录具体时间。
- 记录番茄钟进行到多少分钟/秒时产生该想法。

### PomodoroStepPanel

左侧竖排标签：

```text
步骤
```

右侧内容：

```text
[checkbox] [步骤描述，可编辑]        [完成时间]
```

交互：

- 点击 checkbox：标记步骤完成。
- 完成后：
  - checkbox 打勾
  - 文本划横线
  - 整体变灰
  - 后台记录完成时间和步骤耗时
- 步骤内容可以修改，修改后同步到事件步骤。
- 5 秒内连续完成多个步骤时，不记录步骤耗时。
- 跳步勾选完成步骤时，不记录该步骤耗时。

### PomodoroTimerControls

位置：计时页底部固定。

包含：

- 长条胶囊按钮：暂停专注 / 继续专注
- 下方文本按钮：结束专注

状态：

| Timer 状态 | 主按钮文字 |
|---|---|
| running | 暂停专注 |
| paused | 继续专注 |

点击结束专注：

- 弹出 `EndFocusConfirmDialog`。

## 4. 历史记录页面组件

### PomodoroHistoryPage

用途：展示所有使用过番茄钟的事件。

结构：

- 顶部导航
- 年月选择栏：`xxxx年x月` + 向下箭头
- 历史记录列表
- 空状态

默认展示：

- 当前月份的事件。
- 按“今天 / 昨天 / x日”分组。
- “之前日期”只写日期，不写月份。

历史事件卡片：

```text
[事件标题]                    [已完成 / 未完成]
[打断 N 次  想法 N 条]         [番茄 / 番茄×N]
```

交互：

- 点击年月选择栏：选择年份和月份。
- 点击历史事件卡片：弹出 `HistorySessionDialog`。
- 名称和日期搜索作为增强功能保留入口，首期可以先不做复杂检索 UI。

### HistorySessionDialog

较大卡片弹窗。

展示：

- 事件标题
- 完成/未完成状态
- 预计耗时
- 目的，有内容时显示
- 具体步骤，每一步显示预计耗时
- 实际用时，完成后显示
- 番茄个数，完成后显示
- 打断内容和时间
- 想法内容和时间
- 底部黑色关闭按钮

可编辑区域：

- 目的
- 步骤文本
- 步骤预计耗时

只读区域：

- 打断内容和时间
- 想法内容和时间

保存反馈：

- 编辑后保持卡片内即时更新。
- 后台记录首次内容、最后一次内容和最后修改时间。

## 5. 弹窗组件

### InterruptionInputDialog

用途：录入打断缘由。

MVP：

- 标题：记录打断
- TextField：打断缘由
- 按钮：取消 / 保存

### IdeaInputDialog

用途：录入具体想法。

MVP：

- 标题：记录想法
- TextField：想法内容
- 按钮：取消 / 保存

### EndFocusConfirmDialog

用途：确认是否结束专注。

文案建议：

```text
确定结束本次专注吗？
当前计时将保存为一次番茄钟记录。
```

按钮：

- 继续专注
- 结束专注

### IdeaToInboxCardDialog

用途：session 结束后按顺序询问每一条想法是否加入事件箱。

卡片内容：

- 序号
- 想法内容作为默认标题
- 目的输入区，可修改
- 步骤列表，可添加、编辑
- 每一步预计耗时，可编辑
- 底部“是否加入事件箱”操作区

交互：

- 一次只弹出一条想法卡片。
- 当前卡片选择完毕后，再弹出下一条。
- 全部想法处理完毕后，番茄钟才正式结束并返回。
- 选择加入事件箱时创建 `inbox` 事件。
- 选择不加入时关闭当前卡片并继续下一条。

## 6. 适配规则

### 小屏

- 历史记录最多展示 2 条。
- 事件箱列表高度压缩，但开始组件和添加按钮保持可触达。
- 计时页三个 lane panel 右侧内容区域可滚动。
- 底部暂停/继续按钮固定，避免被内容挤出。

### 中屏

- 历史记录展示 2-3 条。
- 事件箱占主视觉。
- 开始组件保持底部稳定位置。
- 计时页各板块保持圆角矩形。

### 大屏/平板

- 内容最大宽度限制，居中展示。
- 避免卡片横向拉得过宽。
- 计时页 MVP 先保持单列，更利于和手机布局一致。

## 7. 组件复用建议

可复用视觉，不建议复用行为：

- 安排页事件卡片视觉参数。
- 当前详情页底部蓝色按钮风格。
- shared 的耗时格式化和事件标题兜底。
- 主页可拖动添加按钮交互。

不建议直接复用：

- 安排页 `EventBox`，因为它包含 Tab、拖拽、空白跳录入等行为。
- 安排页 `EventCard`，因为番茄钟事件箱需要 checkbox、浅蓝默认态、深蓝选中态，且不接四象限颜色。

## 8. 已确认 UI 规则

- 番茄图标使用自定义图标。
- 自定义番茄图标优先使用透明背景 PNG/WebP。
- 番茄图标可以做“慢慢填满”的简化动画。
- 主按钮不显示“从第 X 步开始”。
- 主页开始组件默认展示“选择一个任务 / 点击选择事件箱中的任务开始专注”。
- 主页开始组件选中后展示事件标题和“预计专注时间：”。
- 步骤编辑同步原事件数据。
- 5 秒内连续完成多个步骤或跳步勾选完成时，不记录步骤耗时。
